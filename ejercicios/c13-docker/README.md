# Mi Proyecto

Proyecto multi-contenedor con frontend y backend utilizando Docker y Docker Compose.

## Estructura de Directorios

```text
mi-proyecto/
├── frontend/
│   ├── Dockerfile
│   ├── package.json
│   ├── .dockerignore
│   ├── .env.example
│   ├── .env
│   └── src/
├── backend/
│   ├── Dockerfile
│   ├── package.json
│   ├── .dockerignore
│   ├── .env.example
│   ├── .env
│   ├── prisma/
│   └── src/
├── docker-compose.yml
├── README.md
└── .gitignore
```

## Requisitos

- [Docker](https://www.docker.com/)
- [Docker Compose](https://docs.docker.com/compose/)
